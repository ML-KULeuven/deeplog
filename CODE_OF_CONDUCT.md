# Code of Conduct

The DeepLog project adopts the **Contributor Covenant, version 2.1**, as its
code of conduct for all project spaces (issues, pull requests, discussions,
documentation, and any other community channels).

The full text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

A plain-text rendering can also be downloaded from:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt>

## Reporting

To report a concern about behavior in DeepLog community spaces, contact the
DeepLog maintainers privately via the DTAI Research Group at KU Leuven
(<https://wms.cs.kuleuven.be/dtai>). Reports are handled confidentially.

For security-sensitive reports, see [SECURITY.md](SECURITY.md) instead.
